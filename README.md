# Anko V2

**Anko** is a personal software development project conceived to explore and master advanced customization capabilities within **Windows Forms**.

Currently, with the release of version **2.0.1**, the project has demonstrated favorable performance and solid results.

---

##  Future Roadmap & Enhancements

For upcoming stages of development, the integration of the following improvements is planned:

* Implementation of **smooth transition animations** when switching between tabs.
* Development of a **bootstrapper featuring an optimized graphical user interface**, designed to replace the traditional command-line interface (CMD).
* Expansion of support and general code optimization.

---

##  Current Project Status

At this stage, development efforts are primarily focused on parallel projects. Consequently, maintenance for **AnkoV2** will be temporarily limited to **updating the corresponding DLLs**.

>  Once the milestones for concurrent projects are met, active and comprehensive development of **AnkoV2** will be resumed.
